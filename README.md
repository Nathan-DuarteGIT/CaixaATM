# Simulador de Caixa Eletrônico (ATM)
Projeto de programação procedural que simula um sistema bancário de múltiplas contas implementando uma Gestão de CRUD (Criação, Leitura, Atualização e Eliminação) completa para contas de utilizador.
O sistema gerencia transações complexas, incluindo validação de saldo (levantamentos/transferências) e atualização de estado de contas.

## Tecnologias Utilizadas ⚙️
Linguagem Principal: C

Ambiente: Console Application

Compilador: CodeBlocks

## Como Instalar/Executar 🚀

### Pré-requisitos
Ter um compilador C (ex: GCC) instalado.

### Passos

1. git clone https://github.com/Nathan-DuarteGIT/CaixaATM.git

2. gcc caixa_atm.c -o caixa_atm

3. ./caixa_atm
